# Shared schemas

Current records: `transition.py` (`State`, `Action`, `ExogenousInput`, `Emission`, `Transition`),
`drive_vector.py`, `manual.py`, `development.py` (version `eight-drive-v1`), and `world.py`
(`WorldState`, `WorldSnapshot`, `GrowthEvent`, `WorldInvariant`, `InvariantReport`, `BranchRecord`,
`InterventionSpec`, and typed world entity records). Existing record shapes and public exports
remain backward-compatible.

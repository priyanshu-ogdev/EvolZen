# Recognition integration

Authority: [Phase 2.3](../../phases/2.3-recognition.md).
Source package: `src/evolzen/recognition/`.

Learn a transferable hypothesis prior only after simpler representations and developmental
baselines are evaluated. The eight-drive controller is not a JEPA encoder, emotional model or
wake-sleep learner. Keep own experiences, parental advice and shared rules separately scoped.
Test whether representation learning improves fresh-context transfer at matched exposure/cost;
do not declare the architecture novel or effective before measuring it.

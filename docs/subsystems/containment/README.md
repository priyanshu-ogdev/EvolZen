# Containment integration

Authority: [Phase 2.2](../../phases/2.2-containment.md) and repository-root `SECURITY.md`.
Source package: `src/evolzen/containment/`.

No motivational ratio can grant a capability. Numeric coefficients are data under a fixed
interpreter; self-modified source code is a different risk and must run through Sandbox.
The developmental core performs no action execution, filesystem writes, model loading or
network access. Feedback and assessment flags are host-only inputs, not authenticated proofs.
A deployed isolation backend is still required before enabling generated code; a Python interface
or restricted namespace is not that backend.

# Phase 1.1 — Environment Engine

**Subsystem:** `evolzen.environment`
**Code:** `src/evolzen/environment/`

## Goal

Build the first persistent, event-sourced, discrete social sandbox for EvolZen. The world must
support agents, locations/resources, artifacts/capabilities, contracts/markets, institutions,
norms/beliefs/manuals, and exogenous events. Its normative transition contract is:

```text
(state_t, action_t, exogenous_input_t, seed) -> (emission_t, state_{t+1})
```

For a fixed complete input record, transitions are deterministic and replayable. The Phase 0
module name `moore_machine.py` is retained for compatibility, but the project uses the more precise
term **seeded, typed interactive transition system**. Exact replay is a mechanistic verification
property, not proof that a causal graph or human intent has been identified.

The first world is deliberately smaller than the original voxel proposal: a persistent graph/grid
of locations, resources, agents, contracts, institutions, norms, and typed capability packages.
Negotiation, markets, and code-with-tests are mechanisms or evaluation slices inside this world,
not alternative definitions of the world.

## What you build

- versioned `WorldSnapshot` records and append-only event logs;
- explicit exogenous-input records and seeded randomness;
- a growth ledger attributing each durable change to an endogenous process, agent action, or
  declared exogenous input;
- snapshot, branch, restore, and replay operations;
- world invariants for conservation, bounded resources, valid ownership, and action legality; and
- a minimal intervention interface for changing one declared variable or withholding one action.

## Success metric

Replay reproduces every emission and next state from the complete logged input. A long run produces
durable growth in at least three allowed categories (for example artifacts, institutions, and
roles), survives a declared environmental shock, and does not require evaluator-injected milestone
events. Hidden mutable state is a failure.

## Citations

Tycho (`arXiv:2607.28287`, preprint) for active identification of discrete rendered environments;
OPINE-World (`arXiv:2607.01531`, preprint) for ontology-error-guided exploration; PettingZoo (Terry
et al., *NeurIPS* 2021, `arXiv:2009.14471`, peer-reviewed) for standardized multi-agent transition
loops; OMNI-EPIC (Faldor et al., `arXiv:2405.15568`, preprint) as a contrasting unbounded
code-environment benchmark (explicitly bounded in EvolZen by ADR 0004). The persistent
social-sandbox contract is an EvolZen design decision and is **untested** until Phase 1.1
experiments are run.

## Research context & breakthroughs

- **Multi-agent standardized transition APIs:** PettingZoo (*NeurIPS* 2021) established deterministic, turn- and parallel-steppable multi-agent interfaces (`AgentEnvironment` / AEC) preventing hidden state leakage across simultaneous actors.
- **Open-ended environment generation vs. bounded extensibility:** OMNI-EPIC (`arXiv:2405.15568`) demonstrated foundation-model-authored code environments, whereas EvolZen deliberately restricts world mutations to versioned capability packages (`WorldSnapshot` + growth ledger) so replayability and causal interventions remain measurable.

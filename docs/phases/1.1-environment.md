# Phase 1.1 — Environment Engine

**Subsystem:** `evolzen.environment`
**Code:** `src/evolzen/environment/`

## Goal

Build the first persistent, event-sourced, discrete social sandbox for EvolZen. The world must
support agents, locations/resources, artifacts/capabilities, contracts/markets, institutions,
norms/beliefs/manuals, and exogenous events. Its normative transition contract is:

```text
(state_t, action_t, exogenous_input_t, seed) -> (emission_t, state_{t+1})
```

For a fixed complete input record, transitions are deterministic and replayable. The Phase 0
module name `moore_machine.py` is retained for compatibility, but the project uses the more precise
term **seeded, typed interactive transition system**. Exact replay is a mechanistic verification
property, not proof that a causal graph or human intent has been identified.

The first world is deliberately smaller than the original voxel proposal: a persistent graph/grid
of locations, resources, agents, contracts, institutions, norms, and typed capability packages.
Negotiation, markets, and code-with-tests are mechanisms or evaluation slices inside this world,
not alternative definitions of the world.

## What you build

- versioned `WorldSnapshot` records and append-only event logs;
- explicit exogenous-input records and seeded randomness;
- a growth ledger attributing each durable change to an endogenous process, agent action, or
  declared exogenous input;
- snapshot, branch, restore, and replay operations;
- world invariants for conservation, bounded resources, valid ownership, and action legality; and
- a minimal intervention interface for changing one declared variable or withholding one action.

## Success metric

Replay reproduces every emission and next state from the complete logged input. A long run produces
durable growth in at least three allowed categories (for example artifacts, institutions, and
roles), survives a declared environmental shock, and does not require evaluator-injected milestone
events. Hidden mutable state is a failure.

## Citations

- **Tycho** (`arXiv:2607.28287`, `tycho2026`): active identification and deterministic replay verification for discrete interactive transition systems.
- **OPINE-World** (`arXiv:2607.01531`, `opineworld2026`): ontology-error-guided exploration and programmatic world-model checking.
- **Executable World Models** (`arXiv:2605.05138`, `executableworldmodels2026`): executable world-model representations checked against recorded transitions.
- **PettingZoo** (Terry et al., NeurIPS 2021, `arXiv:2009.14471`, `pettingzoo2021`): standard Agent Environment Cycle (AEC) multi-agent interaction API wrapped by `SocialSandboxAECEnv`.
- **OMNI-EPIC** (Faldor, Zhang, Cully & Clune, ICLR 2025, `arXiv:2405.15568`, `omniepic2024`): **contrastive boundary** — unlike OMNI-EPIC's unconstrained foundation-model code generation of new environments, EvolZen rejects arbitrary engine mutation in favor of bounded, versioned `CapabilityPackage`s gated by replay, intervention, and containment checks.
- **Procgen** (Cobbe et al., ICML 2020, `arXiv:1912.01588`, `procgen2020`): seed-stratified procedural environment generation precedent motivating explicit seeded world state initialization and held-out seed generalization checks.

The persistent social-sandbox contract, `SocialSandboxAECEnv` integration, and transfer of these precedents to EvolZen's multi-agent setting are EvolZen design choices and remain **untested** empirically until Phase 1.1 long-horizon and target-rig experiments are run.

## Codebase progress match & hardening backlog

- **Implemented Phase 1.1 baseline (`src/evolzen/environment/`, `src/evolzen/schemas/world.py`, `src/evolzen/storage/transition_log.py`):**
  - `SocialSandboxEngine` (`engine.py`) implements `Environment` and `PersistentEnvironment` over `(state_t, action_t, exogenous_input_t, seed) -> (emission_t, state_{t+1})` with zero hidden mutable state on `self`, deterministic RNG via `derive_rng` (`world_state.py`), deterministic `uuid5` `transition_id`/timestamps, and all **17 `ActionType` handlers** (`wait`, `gather`, `move`, `consume`, `craft`, `trade`, `propose_contract`, `fulfill_contract`, `found_institution`, `join_institution`, `contribute_institution`, `propose_norm`, `adopt_norm`, `assign_role`, `spawn_offspring`, `improve_location`, `register_capability`) gated by `CapabilityPackage` verification flags and `world.adulthood_age`.
  - Closed frozen schemas (`extra="forbid"`) in `schemas/world.py` cover all six entity families (`LocationNode`, `WorldAgentState`, `ArtifactRecord`, `CapabilityPackage`, `ContractRecord`, `InstitutionRecord`, `NormRecord`), `ResourceAccounting`, `WorldState`, `WorldSnapshot`, `GrowthEvent`, `WorldInvariant`, `InvariantReport`, `BranchRecord`, and `InterventionSpec`; `Transition` (`schemas/transition.py`) includes `ExogenousInput` and `seed`.
  - `check_invariants` (`invariants.py`), `extract_growth_events` / `summarize_growth` (`growth.py`) across all five `GrowthCategory` buckets, `TransitionLogStore` (`storage/transition_log.py`, `SCHEMA_VERSION = 1` DuckDB JSON-only persistence with SHA-256 hash chaining and atomic `save_snapshot_and_branch`), `replay_transitions` / `replay_from_store` / `branch_from_snapshot` (`replay.py`), `apply_intervention` (`interventions.py`), `adapter` (`observe_features`, `legal_candidates`, `action_from_candidate`, `execute_decision`), `SocialSandboxAECEnv` (`pettingzoo_env.py`), and `run_environment_pilot` (`pilot.py`) are implemented.
- **Open Phase 1.1 production-hardening backlog (empirical success metrics remain unmeasured):**
  - **Replay & intervention bugs:** `replay_transitions` checks `current_state.data != recorded.state.data` but passes `recorded.state` instead of `current_state` to `engine.step` (masking cascading state divergence); `replay_from_store` queries `to_tick=up_to_tick - 1` and filters `tick < up_to_tick`, excluding `same_tick=True` transitions at `tick == up_to_tick`; `apply_intervention` lacks sequence (`tuple`/`list`) indexing in `_set_nested_path` and does not reconcile `ResourceAccounting.initial_currency` on `currency`/`currency_reserve` edits; `SocialSandboxAECEnv.step` lacks `exogenous_input`, `seed`, and `TransitionLogStore` hooks.
  - **Bounded world growth (`FR-2`):** `_handle_spawn_offspring` checks `len(world.agents) >= world.max_agents` against total historical agents (including dead agents, which `invariants.py` forbids removing), halting reproduction once historical count reaches `max_agents`; `WorldState` collections (`artifacts`, `contracts`, `institutions`, `norms`, `capabilities`, `inventory`) lack capacity caps; `WorldAgentState.status` lacks an explicit upper bound; and `GrowthAttribution.ENDOGENOUS_PROCESS` has no active world-tick emitter.
  - **Action coverage & partial mechanics:** `adapter.legal_candidates` surfaces **7 of 17** `ActionType`s (omitting `trade`, `propose_contract`, `fulfill_contract`, `join_institution`, `contribute_institution`, `propose_norm`, `adopt_norm`, `assign_role`, `spawn_offspring`, `register_capability`) and truncates at `max_candidates`; `SocialSandboxAECEnv` discrete space (`Discrete(10)`) covers only basic local actions. `ContractRecord` has no cancel/expiry handler, `_handle_register_capability` accepts only `ActionType.CRAFT`, `InstitutionRecord.contribution_rate` is unenforced with no treasury spending, `ArtifactRecord.durability` does not decay or affect actions, `NormRecord` has no behavioral effect, and `_apply_exogenous` silently ignores unknown event `type`s.
  - **Untested verification & pilot gates:** All 18 failure branches in `invariants.py`, Hypothesis property-based tests for engine/invariants/replay, and long-horizon multi-generation and target-rig hardware pilots remain **untested**; Phase 1.1 empirical success metrics are **not met**.

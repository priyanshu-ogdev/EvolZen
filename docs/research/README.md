For the original developmental-brain design, use the
[agent evidence ledger](../subsystems/agents/evidence.md) and
[matched evaluation protocol](../subsystems/agents/evaluation.md). The inspected primary sources
support component precedents, not the psychological validity of the seven-sins-plus-Null basis.

Standing rule: a design choice in this codebase either traces to an entry in `references.bib`,
or is explicitly flagged as untested. Each source is labeled as peer-reviewed, preprint, vendor
report, or unverified. If you add a citation-backed mechanism, add the citation here first.
